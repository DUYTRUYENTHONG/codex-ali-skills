# Library maintenance

This directory is an inert public catalog, not the runtime's skill installation.
Keep career instructions canonical in Vietnam Career Agent Kit. Update catalog
entries only from immutable source blobs with hashes and license evidence.
No automatic installs, hooks, model dispatch or private candidate content.

For catalog/docs changes, validate JSON, hashes, relative links, canonical skill
count and staged diff. Do not claim native execution from static validation.
Runtime changes elsewhere follow the surrounding Codex project's instructions.
